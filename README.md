## Sobre o Projeto

.A aplicação consiste em um **catálogo de livros** desenvolvido em Java, permitindo realizar operações de **cadastro, consulta, atualização e remoção (CRUD)** de livros.

Cada livro possui:
- ISBN
- Título
- Autor
- Ano de publicação

Para armazenar os livros, foi utilizado um **HashMap**, utilizando o ISBN como identificador único de cada registro.
